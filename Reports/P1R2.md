## 8. Observaciones

 El proyecto pasó de recibir y clasificar datagramas a resolver el caso local `single` y a reenviar consultas no locales mediante la API Java. Se verificó dentro de Kubernetes que `ejemplo.test` devolviera la IP temporal `10.0.0.25` y que una consulta A a `example.com` obtuviera respuesta a través del DNS externo.

El registro `ejemplo.test` sigue definido en memoria: esta verificación demuestra la comunicación entre Rust y Java, pero no demuestra persistencia. Las políticas `multi`, `weight` y `geo`, Supabase, el CRUD, React y HTTPS permanecen pendientes.
